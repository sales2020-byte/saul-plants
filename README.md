# Saul Plant Library – Search Site

Static plant search site (504 plants, 9 categories). Open `index.html`; it loads `plants.json` and photos from `NN-category/img/`.
Photos are resized copies (max 1200px, JPEG q82). No build step; works on GitHub Pages (`.nojekyll` included).
Local preview: `python3 -m http.server` then open http://localhost:8000/
